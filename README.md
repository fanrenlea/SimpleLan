# SimpleLan

进入单人存档时自动开启「对局域网开放（Open to LAN）」。

同一局域网内的朋友可以直接加入，不需要每次都手动点开暂停菜单。

仅在客户端生效，服务器无需安装。

## 特性

- **仅在单人存档中生效。** 加入服务器、局域网联机、Realms 等情况不会触发。
- **不会重复发布。** 如果你已经手动开放过局域网，模组不会再次发布。
- **聊天栏提示端口号**，并在 `remind` 指定的延迟后**再提醒一次**，避免大型整合包的模组信息把首次提示刷掉。（只提醒一次，不会循环；按墙钟计时，不受帧率／tick 率影响，误差不超过一个 tick）
- **发布失败会明确提示**，不会出现「模组好像没运行」的情况。
- 支持 `/simplelan` 命令：查看状态、重新发布、修改默认端口。

## 命令

| 命令 | 说明 |
|------|------|
| `/simplelan` 或 `/simplelan status` | 查看当前发布状态（端口号） |
| `/simplelan republish [port]` | 重新发布（可选指定端口，不填则用配置里的端口） |
| `/simplelan defaults <port>` | 将端口写入配置（下次进存档生效） |

`/simplelan` 是客户端命令，只在单人游戏内可用。

`republish` 会**先绑定新端口，成功后再关闭旧端口**。因此当新端口不可用时，存档会继续在原端口上正常服务，不会掉线。若指定的端口与当前相同，会提示换一个端口而不会做任何改动。

## 聊天提示

自动出现的三条：

| 情况 | 提示 |
|------|------|
| 发布成功 | 原版的「本地游戏已在端口[X]上开启」 |
| 到达 `remind` 延迟后 | `SimpleLan：本地游戏仍在端口X上开启` |
| 发布失败 | `SimpleLan：无法开放端口 X，该端口可能已被占用或需要管理员权限` |

命令回显：

| 命令 | 提示 |
|------|------|
| `/simplelan status` | `SimpleLan：已开放，端口 X` ／ `SimpleLan：未开放` |
| `/simplelan republish` | `SimpleLan：已重新发布，端口 X` |
| `/simplelan republish` 端口不可用 | `SimpleLan：发布失败，端口 X 不可用` |
| `/simplelan republish` 端口与当前相同 | `SimpleLan：已在端口 X 开放，请指定其他端口` |
| `/simplelan defaults` | `SimpleLan：默认端口已写入配置（X），下次进入存档时生效` |
| 未进入单人存档时 | `SimpleLan：请先进入一个单人存档` |

所有端口号均为绿色下划线、点击即可复制，与原版格式一致。

## 配置

配置文件位于游戏目录下的 `config/simplelan-common.toml`。

| 字段 | 默认值 | 说明 |
| ---- | ------ | ---- |
| `enabled` | `true` | 模组总开关，设为 `false` 完全禁用自动发布（`/simplelan` 手动命令仍可用）。 |
| `remind` | `15` | 进入存档后延迟多少秒**再提醒一次**端口号，防止首次提示被其他模组的聊天信息刷掉。**只提醒一次，不会循环**。`0` = 不提醒；`1` 及以上 = 延迟秒数，上限 `3600`（1 小时）。 |
| `port` | `25577` | 监听端口。`0` = 由 MC 自动分配一个空闲端口；其余数值原样使用，上限 `65535`。低于 `1024` 属于特权端口且常被系统占用，可能发布失败。 |

配置项在游戏内的顺序为 **局域网自动开放 → 提醒 → 端口**。

### 在游戏内编辑

安装 [Configured](https://www.curseforge.com/minecraft/mc-mods/configured) 后，可在「模组列表 → SimpleLan → 配置」中直接编辑，选项名与说明均有中英文。

本模组**不声明对 Configured 的依赖**，纯靠约定接入：Configured 会接管所有「没有自带配置界面」的模组。因此没有安装 Configured 时，模组列表里的配置按钮为灰色禁用状态，只能手动编辑 `simplelan-common.toml`，功能不受影响。

## 排查

| 现象 | 原因 |
|------|------|
| 提示端口不可用 | 该端口已被其他程序占用。`1024` 以下的端口常被系统服务占用，且在 Linux／macOS 上需要管理员权限。 |
| 提示发布了，但别人看不到世界 | Minecraft 通过 UDP 组播（`224.0.2.60:4445`）广播可发现信息。路由器、虚拟网卡或防火墙禁用组播时无法被发现，此时让对方用「直接连接」并输入端口号即可正常加入。 |
| 别人能连上但进不去 | 本机防火墙拦截了入站 TCP 连接，需要放行所配置的端口。 |
